# 短视频口播脚本（抖音 / 视频号 / 小红书视频）

> 时长建议 35–45 秒；竖屏 9:16；风格：口语、直接、不堆术语。仓库链接放主页/评论区置顶。

## 黄金三秒钩子（开头任选一条）

- **钩子 A（痛点）**：你给 AI 装了一堆技能，它是不是经常要么想不起来用，要么把活儿派错地方？
- **钩子 B（反常识）**：技能装得越多，越容易乱——缺的不是技能，是中间那个「分诊台」。
- **钩子 C（结果）**：拆书、提炼行业打法、写短剧分镜，我现在让一个调度台先分诊，再交给对应能力干。

## 分段脚本

| 时间 | 口播 | 画面 / 字幕 | 备注 |
|---|---|---|---|
| 0–3s | 钩子（任选 A/B/C） | 近景出镜；大字字幕打出痛点关键词 | 节奏快，不铺垫 |
| 3–10s | 「我搭了个开源的调度台叫 ZYX，干的事就像分诊台：先判断你要哪类东西，再转给对的能力，最后把结果按规矩收好。」 | 切三层结构动画：路由壳 → 执行能力 → 共享底座 | 字幕标出「判类型 / 转委派 / 收口产物」 |
| 10–25s | 「它分六类：一个人、一个行业、一本书或长视频、眼下这个问题、影视短剧生产、还有已有产物再改一版。影视这条链路我把剧本、人物、场景、打斗分镜、表情参数、全流程都接好了。」 | 六条路由逐条弹出图标 + 一句话 | 每条停留约 2 秒，节奏清晰 |
| 25–35s | 「工程上也收口了：依赖写成清单，一条命令装好，自带自检和回归用例，换台机器也能复现。开源 MIT，Claude Code、Codex、OpenClaw、Cursor 这些都能用。」 | 仓库目录 / 安装命令截图 | 命令：`npx skills add zhenliu1486/ZYX` |
| 35–42s | 「仓库放评论区置顶，想攒自己 AI 工作流的可以去看看，有问题提 issue。」 | 出镜收尾 + 仓库地址定格 | 引导关注 / 收藏 |

## 字幕与画面约束

- 大字标题每屏不超过 12 个字；关键词用对比色高亮。
- 口播语速偏快，每句不超过两行字幕。
- 不出现未脱敏的客户名、账号、内部路径。
- 不承诺「装上就能自动出片」：上游蒸馏器需要按清单安装，内置的是 R5 影视七子技能和 R6 迭代器。
