# 豆包公开上架材料（ZYX 安装器）

> 状态：**材料已准备，尚未提交**。公开上架需要豆包开放平台开发者账号 + 企业资质认证 + 平台运营审核；ZYX 仓库不能代替企业提交，也不能绕过审核。

## 一、上架对象

- 技能名称：`zyx-installer`
- 展示名称建议：`ZYX 调度台安装器`
- 版本：`1.9.0`
- 图标：`docs/doubao/zyx-icon.png`（512×512 PNG，18 KB）
- 分类建议：办公效率 / 内容创作 / 开发者工具
- 简介：一句话安装 ZYX 多技能包（19 个技能），覆盖人物/行业/长内容蒸馏、影视短剧制作、产物迭代、长期知识库、A 股四维投资决策与 Pinky 手机操作。
- 仓库：<https://github.com/zhenliu1486/ZYX>
- 许可：MIT（内置 `pinky` 为 Apache-2.0）

## 二、包

```bash
bash scripts/package-doubao-public.sh
```

产物：

| 文件 | 结构 | 用途 |
|---|---|---|
| `dist/doubao-public/zyx-installer.zip` | `SKILL.md` 在 ZIP 根目录 | 豆包文档要求“根目录有 SKILL.md”时用 |
| `dist/doubao-public/zyx-installer-folder.zip` | `zyx-installer/SKILL.md` | 平台要求“一个根文件夹”时用 |

两个包都只有安装器，不嵌套 19 个技能；运行时从 GitHub 取仓库。包体很小，远低于 16 MB / 1024 条目 / 单文件 2 MB 限制。

## 三、示例提示词（5–10 条，审核测试用）

1. 帮我安装 zyx 这个 skill。
2. 用 ZYX 把《穷查理宝典》拆成一套可复用的方法包。
3. 用 ZYX 诊断我这门生意现在最大的瓶颈。
4. 用 ZYX 写一个 60 秒竖屏短剧剧本，并给出分镜和导演机位。
5. 用 ZYX 把这份 PPT 按我的反馈迭代一版。
6. 用 ZYX 建一个关于“Agent Skills”的长期知识库。
7. 用 ZYX 看这只 A 股现在适不适合做 2–4 周波段。
8. 用 ZYX 帮我把这篇文案改得更像真人说的话。

> 手机操作（Pinky）依赖桌面 App + MCP，不建议作为公开商店的首屏测试用例；可放在补充说明里。

## 四、评测报告模板

公开上架要求填写飞书云文档链接，并向审核人员开放阅读权限。把下面内容贴进飞书文档即可：

### 1. 安装验证

- 干净环境（无 `~/.zyx`、无旧 ZYX）执行：
  ```bash
  curl -fsSL https://cdn.jsdelivr.net/gh/zhenliu1486/ZYX@main/bootstrap.sh | bash
  ```
- 预期：19 个技能落盘；`doctor.sh` 输出“基本就绪 / 全部就绪”；缺失项有明确补装命令。
- 记录：系统、Shell、git/python 版本、安装耗时、doctor 原文。

### 2. 路由验证

- 9 条路由各一条最小用例：R1 人物、R2 行业、R3 长内容、R4 当下问题、R5 影视、R6 迭代、R7 知识库、R8 投资、R0 手机（可选）。
- 预期：`route.sh` 返回对应 Skill 绝对路径；未知类型返回非零。
- 运行：`python3 skills/zyx/scripts/route-selftest.py`。

### 3. 安全边界

- 投资：只输出研究框架，不代下单、不承诺收益。
- Pinky：付款/下单/发送/删除等由手机端人工批准；Agent 不能代批。
- 安装：不 push、不打 tag、不发 Release；只写本地。
- 隐私：不把密钥、手机屏幕、验证码、账号、金额、聊天内容写入仓库或公开 issue。

### 4. 已知限制

- 需要 Bash、git、网络；豆包云电脑不能直连本机 Pinky。
- Pinky 仍是 pre-alpha；没有 MCP 工具时只能给安装指引。
- 公开上架后，用户仍需在「豆包推荐」安装；不是聊天里自动搜 GitHub。

## 五、提交步骤

1. 用企业账号登录 <https://open.doubao.com/>。
2. 完成企业资质认证（仅公开上架需要）。
3. 控制台 → 技能列表 → `+ 创建技能` → 选择「公开上架」。
4. 上传 `zyx-installer.zip`（若平台要求根文件夹，改用 `zyx-installer-folder.zip`）。
5. 填写版本 `1.9.0`、分类、评测报告飞书链接、示例提示词、补充说明。
6. 提交审核；通常 3 个工作日，结果站内信通知。
7. 通过后等待统一发版，状态变为「已上架」，出现在「豆包推荐」。
