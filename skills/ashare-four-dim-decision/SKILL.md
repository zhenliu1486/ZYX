# 四维操盘决策

## 角色

这是一个**调度型** Skill：它本身不做四个维度的深度分析，而是调用四个子维度 Skill 得到四张卡，然后完成「加权 → 校验 → 闸门 → 仓位 → 执行时间表 → 复盘」。

四个子维度 Skill 与本 Skill 同级安装。按以下顺序解析路径，找到第一个存在 `SKILL.md` 的目录后 Read 其 SKILL.md 再执行：

1. 环境变量 `$ASHARE_SKILL_DIR`（指向四个子技能的共同父目录）
2. 本 Skill 的兄弟目录：`../ashare-sentiment-cycle`、`../ashare-theme-wind`、`../ashare-capital-flow`、`../ashare-technical-structure`
3. 宿主 skill 目录依次探测：`~/.doubao/agent_mode/workspace/.user_skills/`、`~/.claude/skills/`、`~/.agents/skills/`、`~/.openclaw/skills/`
4. 都不存在：报错「未检测到 ashare-* 子技能，请重装 ZYX 或单独安装」，仓库地址 https://github.com/zhenliu1486/ZYX ，不要凭空假设路径

分工：情绪 `ashare-sentiment-cycle`、风口 `ashare-theme-wind`、资金 `ashare-capital-flow`、技术 `ashare-technical-structure`。

只做单维度问题（如"现在情绪怎么样""这个板块是不是主线"）时，直接用对应子 Skill，不必启动本 Skill 的全流程。

## 六步流程

1. **定时点**：用 `get_current_time` 取当前时间，判断所处交易时段（盘前 / 盘中 / 盘后 / 非交易日），决定用哪个数据口径（见 `references/execution-timeline.md`）。凡是需要落到具体日期的，用 `calculator` 算，不手推。
2. **四维取数打分**：依次调用四个子 Skill，各产出一张标准卡与一个 0-100 分（S_emo / S_theme / S_flow / S_tech）。数据缺失项按各子 Skill 的规则处理，不得编造。
3. **判市场状态 → 取权重 → 算综合分**：执行 `scripts/score.py`（确定性计算，别手算），得到状态、权重、原始加权分、一致性系数与综合分 S。
4. **过风险闸门**：命中任一否决项则强制降级或空仓，不看分数。
5. **映射仓位与候选标的**：按 S 定总仓位上限，按组合约束分配，逐只票给出四个价位（买点/止损/T1/T2）与风险收益比。
6. **输出执行方案**：给出精确到**日期 + 盘中时段 + 动作 + 触发条件**的表，以及失效条件与复盘回填表。

## 动态权重引擎

先判状态，再取权重。状态判别按顺序命中第一条：

| 顺序 | 状态 | 判别条件 | 技术 | 资金 | 风口 | 情绪 |
|---|---|---|---|---|---|---|
| 1 | 系统性风险 | 指数跌破 MA60 / 单日跌 >2% 放量长阴 / --index-broken | — | — | — | — |
| 2 | 题材亢奋 | 情绪分 ≥75 且 风口分 ≥70 | 20% | 25% | 40% | 15% |
| 3 | 退潮冰点 | 情绪分 ≤30，或炸板率 >45% | 30% | 40% | 10% | 20% |
| 4 | 单边趋势 | 指数在 MA20 上方且 MA20 上行，振幅 <1.8% | 40% | 30% | 15% | 15% |
| 5 | 震荡结构 | 其余情况（指数横盘/上下穿梭 MA20） | 35% | 30% | 20% | 15% |

权重的经济含义：
- 趋势市 → 趋势跟随最有效，技术权重给足。
- 震荡市 → 靠结构与资金承接，技术与资金并列。
- 题材亢奋 → 风口是第一驱动，技术退居次要（此时技术"难看"的票照样涨）。
- 退潮 → 资金流向最重要（判断还有没有承接），风口几乎失效。
- 系统性风险 → 不参与，任何分数无效。

用户可手动指定状态或改权重，但要写明理由；手动定权时仍须过闸门。

**一票否决（Risk Gate）任何一条命中即触发：**

1. 指数层面：沪深 300/创业板指跌破 MA60 且 20 日线拐头向下；或单日跌幅 >2% 伴成交额放大 >20%
2. 情绪层面：情绪分 >88 且处于连板高位（追高环境）；或退潮启动信号 4 条中命中 3 条
3. 个股层面：ST/退市风险、审计非标意见、近 30 日公告大额解禁（>10% 流通盘）、业绩预告窗口（财报地雷期）、商誉占净资产 >40%
4. 位置层面：标的连板 ≥5 板追高、近 5 日涨幅 >35%、单日巨量长上影
5. 流动性层面：近 20 日日均成交额 <1 亿元、股东户数异常分散、单票持仓将超总仓 20%

命中 1、2 → 总仓位置 0，只留观察名单；命中 3、4、5 → 剔除该标的，其余照常。

## 综合分 → 动作与仓位

| 综合分 S | 动作 | 总仓位上限 |
|---|---|---|
| ≥80 | 主攻 | 70% |
| 75-80 | 进攻 | 55% |
| 70-75 | 进攻偏谨慎 | 45% |
| 65-70 | 试探 | 35% |
| 60-65 | 观察性试仓 | 25% |
| 55-60 | 极小仓观察 | 15% |
| <55 | 空仓等待 | 0% |

**一致性系数（乘子）**：任一维度 <40 → ×0.85；两个及以上 <40 → ×0.75 并降一档；四维极差 >35 → ×0.90；四维全部 ≥60 → 不打折（共振）。

**组合约束**（与总仓位上限制取小）：单票 ≤20%；同题材合计 ≤40%；单一风口占比 ≤总仓 60%；剩余现金 ≥30%（防守缓冲）。

**为什么能力不够时不硬上**：S 在 55-65 区间意味着四维里至少有一维拖后腿，此时做波段胜率低于赔率要求，宁可小仓试、等结构确认。

## 执行时间表（2-4 周波段的落地方式）

日期全部用真实交易日标注：`D-1 / D / D+1 / D+2 ...` 并在括号里写实际日期（由 `get_current_time` + `calculator` 推算，遇节假日以交易所交易日历为准）。

### D-1 晚间（前一交易日 21:00-22:30）｜选股

- 跑完整四维，得 S 与总仓位上限
- 建候选池（≤5 只），每只填齐买点/止损/T1/T2/风险收益比（<2:1 剔除）
- 写出次日三种开盘情形的应对（高开 / 平开 / 低开）
- 设好次日条件提醒

### D 日（建仓日）｜盘中四段

| 时段 | 动作 | 触发条件 |
|---|---|---|
| 09:15-09:20（可撤单） | 只看不动 | 记录虚拟开盘价、量比、未匹配量，判断是否有抢筹 |
| 09:20-09:25（不可撤单） | 确认高开真实性 | 量比 >3 且高开 ≥3% → 视为强势，转「回踩买」；高开但撤单多/量比 <1 → 视为诱多，放弃 |
| 09:25-09:30 | 定当日策略 | 高开 >3%：不追，挂回踩价；平开（-1%~+2%）：按计划买；低开 <-2%：先看是否破止损，破则当日不动 |
| 09:30-10:00 | **首笔建仓 50% 计划仓** | 分两笔：09:30-09:40 试探 30%，站稳当日均价线后 09:45-10:00 补 20% |
| 10:00-11:00 | **确认加仓 30%** | 回踩不破 MA10 或买点，且分时量能不缩；破位则不加，等 14:30 复核 |
| 11:00-14:30 | 不动 | 唯一例外：跌破止损 → 立即执行止损，不等收盘 |
| 14:30-14:50 | **尾盘补足 20%** | 收盘价站上当日均价 + 当日量 ≥5 日均量 → 补足；否则保留 80% 仓位过夜 |
| 14:50-15:00 | 记录与设置 | 记录成交均价、设次日条件单（止损单 + T1 减仓提醒） |

### D+1 起每个持仓日｜三个检查点

| 时点 | 检查 | 动作 |
|---|---|---|
| 09:25 | 竞价是否低于止损价 | 低于 → 09:30 开盘直接出，不犹豫 |
| 10:30 | 是否跌破 MA20 / 结构下沿；量能是否异常放大 | 破位 → 当日 10:30 前清；放量滞涨 → 减半 |
| 14:45 | 是否触及 T1/T2；是否出现放量长上影 | 到 T1 减半；到 T2 清或留 1/3 底仓；长上影+巨量 → 减 30% |

**卖出规则（四类，先到先执行）：**

1. 止损：跌破止损价无条件出（盘中触发即出，不等收盘）
2. 止盈：T1 减半，T2 全出（或留 ≤1/3 底仓并把止损上移到成本线）
3. 时间止损：持有 5 个交易日无新高且 RS 走弱 → 换股
4. 事件止损：业绩预告不及预期、监管问询、大宗折价 >8% 大额减持 → 直接出

**加仓规则**：仅两种情形允许加仓——突破前高放量（加 ≤20% 计划仓）；缩量回踩 MA10 不破（加 ≤20%）。离成本已超 8% 一律不加。

## 数据不可得时

- 四维中任一维缺数据 → 该维度按 50 分代入，输出标注「缺 + 低置信度」，并在结论卡注明"S 为低置信度版本，建议补齐 __ 数据后复算"
- 超过两维缺数据 → 不给具体买卖价与仓位，只给框架结论与补齐清单
- 绝不允许用"假设""估计"的数字冒充行情数据

## 红线

- 先判状态再算分数，顺序不能反（震荡市用趋势权重会严重高估）。
- 一票否决优先于任何分数，命中即降级。
- 风险收益比 <2:1 的标的不进候选池，不论风口多强。
- 单票 ≤20%、同题材 ≤40%，不做例外。
- 本 Skill 输出研究性操作框架与纪律，不构成投资建议；实盘由用户自行决策并承担风险。

权重表与状态判别的完整说明见 `references/weight-matrix.md`；交易时段与盘口细则见 `references/execution-timeline.md`；打分用 `scripts/score.py`。
