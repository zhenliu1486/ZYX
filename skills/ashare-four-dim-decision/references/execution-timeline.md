# 交易时段、盘口口径与日期推算

## 一、A 股交易时段（北京时间）

| 时段 | 性质 | 能做什么 |
|---|---|---|
| 09:15-09:20 | 集合竞价，**可撤单** | 只观察，不依据此段下单（大量撤单/诱多集中于此） |
| 09:20-09:25 | 集合竞价，**不可撤单** | 判断高开真实性：量比、未匹配量、虚拟开盘价 |
| 09:25 | 开盘价产生 | 核对是否触发止损/放弃条件 |
| 09:30-11:30 | 连续竞价（上午） | 建仓、加仓、止损主战场 |
| 11:30-13:00 | 午休 | 不操作 |
| 13:00-14:57 | 连续竞价（下午） | 确认、修正 |
| 14:57-15:00 | 收盘集合竞价 | 尾盘补仓/减仓的最后窗口 |
| 15:00 后 | 盘后固定价格交易（部分标的） | 可观察暗盘信号 |

## 二、盘口指标口径

- **量比** = 当日开盘后平均每分钟成交量 / 过去 5 日平均每分钟成交量。开盘量比 >3 为明显放量。
- **分时均价线（VWAP 当日）** = 当日累计成交额 / 累计成交量。收盘站上均价线代表当日多头占优。
- **封单额** = 涨停价上未成交买盘金额，越大越强（>1 亿属强封）。
- **封成比** = 封单额 / 当日成交额，>1 为强，<0.3 为弱。
- **炸板** = 触及涨停后打开，打开后再次封回叫"回封"。

## 三、不同时点该用什么数据

| 时点 | 数据口径 | 四维处理 |
|---|---|---|
| 前一交易日盘后（15:00-次日 09:00） | 完整收盘数据 | 全流程正常执行，这是**唯一可给出完整买卖计划**的时点 |
| 当日盘前（09:00-09:15） | 昨日收盘 + 隔夜消息 | 沿用昨日四维，仅对风口做隔夜消息修正 |
| 当日盘中（09:30-15:00） | 实时快照 | 情绪/资金用替代指标（见 sentiment 的盘中快照节），只允许修正当日动作，不得推翻前一日阶段判定 |
| 非交易日（周末/节假日） | 最近交易日收盘 | 做计划与复盘，标注"以最近交易日 YYYY-MM-DD 数据为基准" |

## 四、日期推算规则

1. 用 `get_current_time` 取当前时间，判断今天是否交易日。
2. `D` = 下一个交易日；`D-1` = 最近已收盘的交易日；`D+N` 按交易日顺推，**不是自然日**。
3. 具体日期用 `calculator` 计算，遇周末顺延；遇法定节假日（春节、清明、劳动节、端午、中秋、国庆、元旦）以当年交易所交易日历为准，无法确认时用 `general_search` 查"A股 交易日历 休市安排"，仍无法确认则在输出中写"日期需按交易日历核对"，不得臆造。
4. 输出时必须同时写"交易日序号 + 实际日期 + 星期"，例：`D+1（2026-11-13 星期五）`。

## 五、执行表写法示例

| 交易日 | 日期 | 时段 | 动作 | 触发条件 |
|---|---|---|---|---|
| D-1 | 2026-11-12 | 21:00-22:30 | 复盘选股，出候选池 | 完成四维打分，S≥65 才进候选池 |
| D | 2026-11-13 | 09:20-09:25 | 确认开盘强度 | 量比 >3 且高开 ≥3% → 改回踩买 |
| D | 2026-11-13 | 09:35-09:45 | 首笔试探 30% 计划仓 | 不跌破买点下沿 18.50，分时站上均价线 |
| D | 2026-11-13 | 09:50-10:00 | 补 20% | 量比 >1.5 且未冲高回落 |
| D | 2026-11-13 | 10:00-11:00 | 加仓 30% | 回踩不破 MA10（18.35）且缩量 |
| D | 2026-11-13 | 14:30-14:50 | 补足 20% | 收盘前站上均价线，当日量 ≥5 日均量 |
| D+1 | 2026-11-16 | 09:25 | 止损检查 | 竞价低于止损价 17.80 → 09:30 直接出 |
| D+1 | 2026-11-16 | 10:30 | 结构检查 | 跌破 MA20 或放量滞涨 → 减半 |

（上表为格式示例，日期需按实际交易日历核对。）

## 六、常见执行偏差

- 把"D+1"当成自然日次日 → 周五算成周六，全盘错位
- 09:15-09:20 看到大买单就冲进去 → 该阶段可撤单，诱多集中
- 高开 5% 还去追 → 波段首笔成本过高，止损空间被压缩
- 尾盘补仓不看量能 → 无量补仓等于主动接浮筹
- 止损"等收盘再说" → 波段止损必须盘中执行，收盘价已失真
