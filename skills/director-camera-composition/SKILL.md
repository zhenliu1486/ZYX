## 「这个技能是干什么的」

> **一句话**：别人给剧本或提示词，我把它变成"这一场该用什么机位、怎么运动、为什么"。
>
> **两种用法**
> - **A 剧本 → 镜头方案**：给一段剧情/分镜，出镜头表（几镜、每镜五决策、每镜提示词、每镜为什么）
> - **B 提示词 → 诊断重写**：给一条现成的生视频提示词，找出"为什么平"，只改机位与运动，重写一版
>
> **它不做什么**：不做风格堆砌、不做滤镜、不给"电影感"这种词。它只回答一件事——
> **这一镜要让观众感觉到什么，所以相机应该在哪、怎么动。**

# 导演运镜与机位构图

> 方法层，跨项目复用。具体片子的判读与教案进各自项目目录，不要写回这里。

---

## 〇、一条总纲（先记住这个，其它都是推论）

> **情绪 = 观众与主体的距离 + 观众相对主体的高度 + 观众被允许看多久。**
>
> 机位不是风格选择，是情绪的物证。想让观众靠近就缩短距离；想疏远就拉远抬高；想不安就破坏水平。

所以本技能永远从**情绪**进门，不从**机位名词**进门。先问"这一镜让人感觉到什么"，再问"用哪个角度"。

## 一、能力清单（这个技能能做到的事）

| 能做 | 产出 |
|---|---|
| 把一段剧本/剧情梗概变成可执行的镜头表 | 场戏分析 + 3–6 镜，每镜含五决策、提示词、为什么、接点 |
| 判断一场戏"为什么不好看"并给出镜头层解法 | 诊断（情绪平？信息缺？方位乱？节奏塌？）+ 具体改法 |
| 给某一情绪配镜头 | 12 种情绪 × 六维处方（距离/高度/朝向/焦段/构图/运动） |
| 改造别人写的生视频提示词 | 四查诊断 → 只改机位与运动 → 重写 200–300 字中文提示词 |
| 排一场情绪有起伏的戏 | 收紧/松开/破水平三种走法，保证情绪曲线可读 |
| 竖屏 9:16 的构图与运动适配 | 原生构图三条铁律 + 竖屏运动禁区 |
| 交付分镜表 | 六行格式：镜头/为什么/画面提示词/视频提示词/当心/接点 |

## 二、主流程 A：剧本 → 镜头方案

### 第 1 步 · 逼出一句话
问（或自答）：**这场戏要观众带走什么？**
不是"两人吵架"，是"原来他一直知道"。写不出这句，后面全是白排。

### 第 2 步 · 拆 beat
beat ＝ 关系或信息发生变化的最小单位。30 秒的戏通常 2–3 个，超过 4 个说明想说的太多。
**一个 beat 只给一个情绪词。**

### 第 3 步 · 查情绪处方
按 `01-emotion-shot-map.md` 取六维组合。
情绪必须**有变化**：整场按"收紧"（越来越近、越来越低、越来越慢）或"松开"（越来越远、越来越高、加负空间）排。全场同一个情绪＝平。

### 第 4 步 · 按 beat 配镜
按 `02-beat-shot-plan.md` 的八种 beat 配比取骨架。
每个 beat 至少要有"给信息的一镜"＋"给反应的一镜"。

### 第 5 步 · 填五决策 + 接点
每镜五决策各只能有一个答案；序列补第六项接点（怎么交给下一镜）。

### 第 6 步 · 写成提示词
按 `07-prompt-writing.md` 的中文九段公式，一镜一句，200–300 字。

## 三、主流程 B：现成提示词 → 诊断 + 重写

拿到别人（或自己）的提示词，**先判断它属于哪种病**，不要一上来就改词。

### 四查（按顺序查，第一个中的就是主因）

| 查什么 | 症状 | 怎么改 |
|---|---|---|
| **1. 有没有回答"相机在哪"** | 只有主体和形容词，没有景别/角度/镜头 | 补五决策（`03`） |
| **2. 机位对不对情绪** | 有角度，但用错了（孤独给特写、压迫给大远景） | 按 `01` 换处方 |
| **3. 运动有没有三参数** | 写了"缓慢推进"，没有速度、没有终点；或者叠了三个运动 | 补速度+终点；砍成单运动（`04`） |
| **4. 有没有自相矛盾/否定句** | "俯拍虫视""不要出现人""电影感" | 去矛盾、改正向、换成具体事实 |

### 重写规则
- **只动机位与运动**，主体的动作与外观一个字别动（用户认的是那个主体）。
- 保留用户原意的画幅与风格词。
- 输出：**改前 / 改后 / 三句话说明为什么**。说明里必须指出"原稿病在哪一条"。

## 四、十二种情绪速查（详情见 `01`）

| 情绪 | 一眼取用 |
|---|---|
| 压迫 / 被控制 | 近景 · 高角度或头顶压物 · 中长焦压缩 · 极缓推或固定 |
| 孤独 / 疏离 | 大远景 · 略高 · 背面 · 广角 · 大负空间 · 拉出 |
| 亲密 / 信任 | 近景特写 · 平视略低 · 四分之三 · 85mm 浅景深 · 固定 |
| 紧张 / 危险 | 中近景 · 前景遮挡 · 过肩/背面 · 长焦窥视 · 手持微抖 |
| 失控 / 崩溃 | 大特写 · 斜角手持 · 广角畸变 · 破水平 · 强调用推轨变焦 |
| 权力 / 威压 | 中景全身 · **低角度** · 正面 · 标准焦 · 居中对称 · 固定 |
| 渺小 / 敬畏 | 大远景 · 航拍/高角度 · 背面 · 广角深焦 · 极缓升高 |
| 希望 / 释放 | 近景拉远 · 由高转平 · 侧背 · 视线留空 · 拉出+升起 |
| 怀旧 / 记忆 | 中远景 · 略高 · 四分之三 · 浅景深 · 暖调低饱和颗粒 |
| 悬念 / 未知 | 中景给一半 · 前景遮挡 · 背面剪影 · 长焦 · 缓移或固定 |
| 愤怒 / 对抗 | **双方等景别等高度** · 正面 · 35–50mm · 顶满画框 · 固定密切 |
| 悲伤 / 失去 | 中景或背影远景 · 略高 · 侧背 · 负空间 · **固定（不要运镜）** |

**三条最容易踩的错**：
1. 孤独给特写（一靠近就不孤独了）
2. 悲伤配推轨变焦（那是崩溃，不是悲伤）
3. 全片都紧张 / 全片都斜角（没有对比，情绪就不成立）

## 五、六维落地（每镜必答，留空＝交给模型瞎猜）

1. **距离**：大远景 / 远景 / 中景 / 中近景 / 近景 / 大特写
2. **高度与水平**：地面 / 平视 / 高位 / 俯拍正扣 / 鸟瞰 / 航拍 / 虫视；地平线是否倾斜
3. **朝向**：正面 / 侧面 / 四分之三 / 背面 / 过肩 / 第一人称 / 自拍
4. **镜头与焦点**：广角畸变 / 标准 / 长焦压缩 / 微距；浅景深或深焦；前景遮挡
5. **运动**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升 / 手持 / 环绕 / 变焦 / 推轨变焦 —— **种类 + 速度 + 终点**
6. **接点**（序列才有）：硬切 / 动作切 / 遮挡切 / 首尾帧桥 / 甩镜

同一条只能有一个答案。"俯拍虫视""微距大远景"会让模型随机挑一个。

## 六、写提示词：三件事

1. **镜头句放最前面**（画幅→景别→机位→镜头），主体细节在后。前面的话权重最高。
2. **说清这个角度要达成什么，并给一个只有它才有的视觉证据**。
   例："让人显得被困" → "天花板的横梁压在画面上三分之一"。
3. **一镜一个运动，有速度有终点**。要静止就明写"相机固定在三脚架上"。

加分：**把机位锚在实物上**——"机位贴在吧台台面上"比"低角度"稳得多。

## 七、自检清单（每版都过）

- [ ] 这场戏的"一句话"写得出吗？
- [ ] 每个 beat 有情绪词，且整场情绪**有变化**？
- [ ] 每一镜的机位能对上 `01` 的处方，不是随手选的？
- [ ] 六维各只有一个答案，没有互相矛盾？
- [ ] 主体与机位的关系说得清"为什么"，不是"我觉得好看"？
- [ ] 相邻两镜换了景别或角度？180° 线守住了？
- [ ] 运动：一个、有速度、有终点？
- [ ] 提示词：镜头句在最前、无否定句、无"电影感"这类空词？
- [ ] 是竖屏的话，构图是原生设计还是裁的？

## 十、来源与边界

- 框架重组自两个 MIT 开源 Claude Skill：`joost/ai-camera-shots`（五决策、34 镜型、转场、检查清单）、`Rylaispirit/cinematic-video-prompt-skill`（词表广度）；术语另注 GenHQ × Magnific《34 Shot Prompt Guide》。
- **情绪→六维处方、beat→镜头配比、情绪转换三种走法、提示词四查、中文公式与字数口径、竖屏章、拉片反推法**为本项目自撰，按 Seedance 2/2.5、可灵、9:16、≤30 秒的实际生产约束改写。
- 180° 线与 30° 法则是通行规则，此处只写操作口径。
- **不含**：灯光与调色系统、剪辑节奏与声音、具体影片的判读结论。
