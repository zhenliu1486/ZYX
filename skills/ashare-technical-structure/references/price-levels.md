# 价位算法与形态识别细则

## 一、均线结构判定表

| 状态 | 特征 | 波段含义 |
|---|---|---|
| 完美多头 | 5>10>20>60，间距递增，20 日线上行 | 最优，回踩 MA10 买 |
| 多头但粘合 | 均线间距 <3%，方向不明 | 等突破方向，不预判 |
| 纠缠 | 均线相互穿插 5 日以上 | 结构混乱，不做 |
| 空头反抽 | 5<10<20 但 5 日线拐头向上 | 只做短线反抽，不做波段 |
| 空头排列 | 5<10<20<60，60 日线下行 | 禁止做多 |

## 二、关键价位计算示例

已知：平台高点 18.90，前低 17.10，ATR = 0.72，MA10 = 18.35，MA20 = 17.95

- 买点一 = 18.90 × 1.005 = 19.00
- 买点二 = 18.35 × 1.01 = 18.53（取 max(MA10, MA20)）
- 止损候选：
  - 买点 1 的 96% = 18.24
  - 前低 17.10 × 0.99 = 16.93
  - 买点 1 - 1.5×ATR = 17.92
  - 取最高者 = 18.24
- T1 = 买点 1 + 2×ATR = 20.44（若上方有更明确的压力位，取压力位）
- T2 = 突破位 + 1.382 × 平台高度（18.90 - 17.10 = 1.80 → 1.382×1.80 = 2.49）= 21.39
- 风险收益比 = (20.44-19.00)/(19.00-18.24) = 1.44/0.76 = 1.9 → 略低于 2，需等回踩买点二或抬高 T1

## 三、形态识别要点

**平台突破**
- 横盘 ≥15 个交易日，最高最低振幅收窄至 <12%
- 突破当日量 ≥ 5 日均量 1.3 倍，收盘价站稳上沿
- 假突破判定：突破后 3 日内收回平台内且量能萎缩 → 止损出

**缩量回踩**
- 量能萎缩至 5 日均量 60% 以下
- 回踩不破 MA10（强势）或 MA20（次强）
- 出现下影线 + 次日阳线覆盖 → 企稳确认

**旗形整理**
- 急涨 ≥15% 后回调幅度 <8%
- 回调期缩量，时间 3-8 日
- 突破前高即入场

**圆弧底/双底**
- 底部时间 ≥20 日，两底价差 <3%
- 颈线突破时放量，回踩颈线不破即买

## 四、背离识别

- 顶背离：价格新高，MACD 高点下移，或量能萎缩 30% 以上
- 底背离：价格新低，MACD 低点上移，量能地量
- 背离只作警示，不作为单独买卖信号，需配合结构破位确认

## 五、筹码与套牢区

- 上方 10% 以内存在过去 60 日成交占比 >15% 的密集区 → 视为压力
- 突破后该密集区被消化（逐步缩量穿越）→ 结构转强
- 底部单峰密集（占 60 日成交 >40% 且集中于现价 ±5%）→ 洗盘结束信号

## 六、常见技术陷阱

1. 用最高价而非收盘价算平台高点 → 买点偏高
2. 止损设得太远（用前低而不是 ATR 约束）→ 单笔亏损失控
3. 上涨缩量当作健康 → 波段中途缩量上涨常是资金退出
4. 均线金叉但 20 日线下行 → 下跌中继，不是趋势反转
5. 只看日线忽略周线破位 → 逆势做多
6. ATR 过大（>9%）的票做波段 → 止损频繁被扫
