# 题材分类与产业链卡位

## 一、题材四种类型（决定能拿多久）

| 类型 | 驱动 | 典型 | 可持续性 | 波段可行性 |
|---|---|---|---|---|
| 政策型 | 部委/地方文件、规划、补贴 | 设备更新、以旧换新、专项债投向、新质生产力 | 3-8 周，节奏跟政策落地 | 高（可拿 2-4 周） |
| 产业型 | 涨价、订单、技术突破、产能出清 | 存储涨价、固态电池、机器人零部件、算力租赁 | 1-6 个月 | 最高 |
| 事件型 | 展会、招标、财报、并购 | 行业大会、中标公告、重组 | 1-5 个交易日 | 低（只做短线） |
| 情绪型 | 概念联想、海外映射、段子 | 玄学概念、跨界蹭热点 | 1-3 个交易日 | 极低（不参与） |

判断优先级：**产业型 > 政策型 > 事件型 > 情绪型**。波段只做前两类。

## 二、产业链卡位三层

```
上游（材料/资源）—— 涨价直接受益，弹性最大，业绩最快体现
中游（制造/加工/设备）—— 量增受益，看订单与产能利用率
下游（应用/终端）—— 概念最虚，多数只沾边
```

选票优先：**直接受益的上游或核心中游**，避开只做下游沾边的。

## 三、扩散路径（预判轮动）

1. 龙头启动（1 只）
2. 同环节跟随（2-4 只）
3. 板块内二三线扩散（10+ 只）→ 扩散度 >70% 通常是高潮前兆
4. 跨板块联想扩散（其他板块沾边股涨停）→ 高潮末端，撤退信号
5. 龙头补跌、杂毛先跌 → 退潮

## 四、板块强度跟踪表（每日更新）

| 日期 | 板块 | 5日涨幅 | 成交额占比 | 涨停家数 | 最高板 | 扩散度 | 阶段 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

连续 3 日占比上升 + 板块分 >70 → 主线确认。

## 五、拥挤度与风险

- 板块成交额占比（该板块 / 全市场）：<3% 冷启动｜3-8% 健康发酵｜8-10% 偏热｜>10% 拥挤警戒｜>15% 见顶风险
- 板块内换手率中位数 >15% 且股价滞涨 → 出货
- 融资余额板块占比快速抬升 → 杠杆资金拥挤，波动放大
- 龙头成交额占板块 >40% → 板块=一只票，风险高度集中

## 六、跨市场映射

美股同类标的大涨（如算力、半导体设备）→ A 股次日大概率有映射，但**只映射到真受益标的**，蹭概念的次日冲高就是卖出机会。

## 七、常见伪风口

- 只有公告没有订单的「签约概念」
- 公司自己发公告蹭热点（互动易/公告澄清后又改口）
- 只有一个龙头的「板块」，其余全是跟风一字板散户
- 老题材第 N 次重提，无新增催化
