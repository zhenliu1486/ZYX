# 增量认知校验（增量先验法）

> **引用方与挂载阶段**：女娲（R1，抽取前）、大师（R2，调研前）、仓颉（R3，RIA 抽取前）；zyx 收口时复核。挂载阶段：蒸馏/抽取前置步骤。
>
> 三方蒸馏器重复出现的同一套前置动作：先把模型/自己已经知道的写下来，再把精力花在「和已有认知不一样」的地方。本文件是共享口径，女娲、大师、仓颉在抽取前都按此执行。

## 1. 为什么先写已有认知

蒸馏的价值不在复述常识，而在模型不看这份材料就答不出来、答不准、答得浅的部分。调研前先显式写下已有先验，后续才能识别三类增量：

- **推翻**：大众印象/模型先验是错的，一手材料说的是另一回事。
- **加深**：方向对但先验是空的，现在有了具体案例、条件、原话和出处。
- **新增**：先验里根本没有的招式、决策路径和转折。

模型本来就知道的常识（如「芒格讲逆向思考」「乔布斯讲专注」）不占篇幅；写三百行也没有增量。

## 2. 执行步骤

1. **记录先验**：在抽取开始前，用 3～5 条写下「关于这个人/行业/这本书，我（模型）默认已经知道什么」。
2. **定向找反例与差异**：调研时优先找与先验不一致的一手材料：原话、原始案例、时间线、决策记录，而不是重复印证先验的二手评论。
3. **标注增量类型**：每条候选结论标注属于 推翻 / 加深 / 新增 中的哪一类；找不到增量的条目降级为背景参考，不进产物正文。
4. **增量篇幅配比**：产物正文篇幅向增量倾斜；常识性内容只做一句带过或放参考区。

## 3. 判据与边界

- 一条材料只有「正确的废话」、谁都能说出来，不入选。
- 先验记录允许被推翻：调研后发现先前写的先验本身有误，在产物里显式修正，并标注修正依据。
- 本步骤只解决「找什么、留什么」；是否可执行、是否有任务增益，交给 `../verification/triple-verification.md`。
