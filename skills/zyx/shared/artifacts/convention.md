# 产物目录规范与模板

> **引用方与挂载阶段**：女娲（R1 人物 Skill）、大师（R2 行业 Skill）、仓颉（R3 编译产物）、dbs（R4 诊断/成稿）、video-studio（R5 剧本/设定/分镜）、f2r（R6 迭代产物）；zyx 收口统一落点。挂载阶段：产物落盘与清单生成环节。
>
> 统一所有蒸馏器产物的目录结构、命名与清单文件。仓颉编译产物、女娲人物 Skill、大师行业 Skill、dbs 产物收口时都遵守本规范。

## 1. 标准产物目录结构

```
<产物 slug>/
├── SKILL.md              # 产物主文件（可安装 Skill 时必备；纯报告类可替换为 REPORT.md）
├── references/           # 参考资料、理论锚点、补充说明（可选）
├── scripts/              # 确定性脚本（可选；纯方法包可无）
├── assets/               # 模板、图表、素材（可选）
├── sources/              # 来源元数据与最短摘录（编号 + 可信度分级）
├── evals/                 # Darwin 式压测用例与结果（适用时）
└── MANIFEST.md            # 产物清单与审计记录（必备）
```

## 2. 命名

- 目录 slug：小写英文 + 连字符，或中文短名；不含空格、特殊字符。
- 文件名见名知意，不用 agent id、会话 id、临时文件名。
- 重复蒸馏新版本加日期后缀 `YYYYMMDD`，不覆盖旧目录；覆盖前先备份。

## 3. MANIFEST.md 模板

```markdown
# 产物清单：<产物名称>

- 来源 Skill：<R1 女娲 / R2 大师 / R3 仓颉 / R4 dbs> <版本号>
- 生成时间：YYYY-MM-DD HH:MM
- 原料类型：<人 / 行业 / 长内容 / 当下问题>
- 产物路径：<绝对路径>

## 内容清单
| 文件 | 说明 |
|---|---|

## 来源与可信度
| 编号 | 来源 | 级别（一手/二手/推断） | 摘录/元数据 |
|---|---|---|---|

## 验证记录
- 增量类型：推翻 / 加深 / 新增
- 三重验证：A 来源 / B 可执行 / C 增益，逐项通过情况
- 压测：用例数 / 通过 / 回炉淘汰（见 evals/）

## 边界与限制
- 适用条件：
- 反例 / 失效条件：
- 未覆盖部分：

## 修改记录
| 日期 | 改动 | 依据 |
|---|---|---|
```

## 4. 与路由收口的衔接

- 产物一级子目录按来源 Skill 名分目录，规则见 `../../references/artifact-layout.md`。
- 纯报告/成稿类产物（dbs 居多）可无 `SKILL.md`，但 `MANIFEST.md`、`sources/` 仍保留。
- 可安装 Skill 产物另需符合 agentskills.io 规范：frontmatter、渐进式披露、500 行以内正文。
