# 分镜表模板与示例

## 标准分镜表格式

| 镜号 | 景别 | 画面描述 | 人物 | 动作/表情 | 场景 | 提示词 | 负面词 | 时长 | 运镜 |
|---|---|---|---|---|---|---|---|---|---|

---

## 填写说明

### 各列填写要求

1. **镜号**：集数-序号，如 1-01、1-02
2. **景别**：特写/近景/中景/全景/远景
3. **画面描述**：一句话说清这镜拍什么
4. **人物**：出场人物名
5. **动作/表情**：人物在做什么、什么情绪
6. **场景**：用哪个场景参考图
7. **提示词**：完整的生图英文提示词
8. **负面词**：通用负面词即可
9. **时长**：2-5秒
10. **运镜**：推/拉/摇/移/跟/固定

## 常见景别使用指南

| 景别 | 适用场景 | 情绪强度 |
|---|---|---|
| 大特写 | 眼睛、眼泪、手指等细节 | 极强 |
| 特写 | 面部表情、情绪重点 | 强 |
| 近景 | 对话、上半身 | 中强 |
| 中景 | 对话+手势、动作 | 中 |
| 全景 | 交代环境、人物关系 | 中弱 |
| 远景 | 大场面、孤独感、结尾 | 弱 |

---

## 运镜选择指南

| 运镜 | 效果 | 适用场景 |
|---|---|---|
| 固定 | 客观、冷静 | 对话、对峙 |
| 推（近） | 强调、发现、情绪加强 | 情绪递进、关键台词 |
| 拉（远） | 疏离、结束、孤独 | 结尾、转场 |
| 摇 | 展示环境、跟随 | 转场、大场景 |
| 移 | 流动、跟随 | 走路、对话移动 |
| 跟 | 紧张、动感 | 追逐、动作 |
| 升 | 升华、史诗感 | 结尾、大场面 |
| 降 | 压迫、沉重 | 进入紧张场景 |
