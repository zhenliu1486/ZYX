## 剧本拆分检查

- [ ] 每镜是否只讲一件事（一个动作/一句台词）
- [ ] 单镜时长是否在2-5秒之间
- [ ] 每集总时长是否控制在2-3分钟
- [ ] 人物出场是否连贯，无莫名消失/出现
- [ ] 场景转换是否有逻辑（不会从办公室突然到家）
- [ ] 情绪曲线是否有起伏（不能全程平）
- [ ] 开头3秒是否有钩子（抓人）

---

## 定妆照检查

### 人物定妆
- [ ] 正面半身，面部清晰
- [ ] 服装完整展示（全身或至少半身）
- [ ] 光线均匀，无过暗/过曝
- [ ] 特征明显（发型、标志性配饰）
- [ ] 无AI感（塑料皮肤、畸形等）
- [ ] 同一人物多角度（正面、侧面、3/4面）各一张

### 场景定妆
- [ ] 空镜（无人物），空间完整
- [ ] 主色调明确（冷/暖）
- [ ] 有标志性元素（一眼能认出是哪个场景）
- [ ] 日景/夜景各一张（如需）
- [ ] 构图居中，便于后续合成

---

## 分镜表检查

- [ ] 镜号连续，无跳号
- [ ] 每镜景别是否合理（对话用近景，交代用全景）
- [ ] 提示词是否包含：人物+动作+场景+光影+画质
- [ ] 负面词是否统一
- [ ] 运镜是否与情绪匹配
- [ ] 时长累加是否等于总时长

---

## 图片生成检查

### 人物一致性
- [ ] 面部是否与定妆照一致
- [ ] 发型是否正确
- [ ] 服装是否正确（颜色、款式）
- [ ] 标志性配饰是否在

### 场景一致性
- [ ] 背景是否与场景参考一致
- [ ] 色调是否统一
- [ ] 时间是否正确（日景还是夜景）

### 技术质量
- [ ] 无畸形（手、脸、身体）
- [ ] 无水印、无文字、无logo
- [ ] 无多余人物
- [ ] 表情是否匹配台词情绪
- [ ] 构图是否合理（主体位置、留白）

---

## 视频生成检查

- [ ] 人物动作自然，无抽搐
- [ ] 嘴型（如有说话）基本匹配
- [ ] 运镜是否平稳，无突然抖动
- [ ] 时长是否正确（3秒还是5秒）
- [ ] 运动方向是否符合逻辑
- [ ] 画面无闪烁、无跳帧
- [ ] 人物面部保持一致（不崩）

---

## 成片检查

### 节奏
- [ ] 开头3秒是否抓人
- [ ] 每15秒是否有一个小高潮/反转
- [ ] 结尾是否有钩子（留悬念）
- [ ] 整体节奏不拖沓，无冗余镜头

### 音画
- [ ] 口型与配音基本同步
- [ ] BGM情绪与画面匹配
- [ ] BGM音量不盖过人声
- [ ] 有环境音效（脚步、风声等）
- [ ] 转场自然，无硬切突兀

### 字幕
- [ ] 字幕位置正确（底部居中）
- [ ] 白字黑边，清晰可读
- [ ] 无错别字
- [ ] 字幕时长与语音匹配

### 整体
- [ ] 色调统一，无忽明忽暗
- [ ] 人物外观前后一致
- [ ] 无穿帮（场景、服装前后矛盾）
- [ ] 画幅正确（9:16竖屏）
- [ ] 总时长符合平台要求（短剧1-3分钟/集）
