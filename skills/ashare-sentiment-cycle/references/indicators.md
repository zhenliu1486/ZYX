# 情绪指标口径与阈值速查

## 一、指标定义（口径必须写清，否则每天数字不可比）

| 指标 | 定义 | 计算要点 |
|---|---|---|
| 涨停家数 | 收盘封住涨停的股票数 | 剔除 ST、剔除新股首日；主板 10cm 与创业板/科创 20cm 分列 |
| 封板率 | 收盘仍涨停 / 当日曾涨停 | 需盘中触板记录，收盘数据无法还原时用「涨停 + 炸板」近似 |
| 炸板率 | 1 - 封板率 | 与封板率必须同源 |
| 连板高度 | 连续涨停天数最大值 | 以交易日连续为口径，停牌日不计 |
| 晋级率 | 昨日涨停股今日仍涨停的家数 / 昨日涨停家数 | 情绪最灵敏的先行指标 |
| 昨日涨停溢价 | 昨日涨停股今日平均涨跌幅 | 用等权平均；剔除一字板可另算「可买溢价」 |
| 大面股 | 当日跌幅 >7% 的个股数 | 与跌停家数配合看恐慌 |
| 成交额环比 | 当日全市场成交额 / 近 5 日均值 | 用 5 日均值平滑，避免单日异常 |
| 涨跌家数比 | 上涨家数 / 下跌家数 | >2 为普涨，<0.5 为普跌 |
| 赚钱效应指数 | 上涨家数占比 × 昨日涨停溢价方向 | 定性辅助，不进打分 |

## 二、分档阈值（历史经验值，可按牛熊调整）

- 涨停家数：冰点 <30｜常态 50-70｜活跃 80-100｜亢奋 >120
- 跌停家数：健康 <5｜警惕 5-15｜恐慌 >20
- 封板率：强 >80%｜中性 65-80%｜弱 <60%
- 炸板率：强 <20%｜中性 20-35%｜弱 >40%
- 晋级率：强 >45%｜中性 25-45%｜弱 <20%
- 最高板：无主线 ≤3｜正常 4-6｜亢奋 ≥7
- 全市场成交额：地量 <8000 亿｜常态 1-1.5 万亿｜活跃 1.5-2 万亿｜亢奋 >2.2 万亿

## 三、情绪周期与指数周期的错位

- 指数上涨 + 情绪退潮 → 顶背离，1-3 周内大概率调整，减仓。
- 指数横盘 + 情绪升温 → 结构性行情，最舒服的波段环境，加仓。
- 指数下跌 + 情绪冰点后首次回升 → 底部区域，分批建底仓。
- 指数与情绪同步下行 → 全面防守，只留现金与防御仓。

## 四、盘中情绪快照（10:30 / 14:30）

盘中只能用替代指标，不要硬套收盘口径：

1. 涨停家数（实时）+ 炸板家数
2. 昨日涨停股今日平均涨幅（实时）
3. 竞价高开家数占比、竞价一字板数量
4. 5 分钟内涨速榜前列个股所属板块（判断风口方向）

盘中快照只用于修正当日动作（是否加仓/是否减半），不用于推翻前一日的阶段判定。

## 五、数据获取失败的处理

任一字段缺失时：
- 单字段缺失 → 按 50 分代入，输出标注「缺」
- 超过 3 个字段缺失 → 情绪分标记为「低置信度」，在四维加权中权重打 7 折
- 全部缺失 → 只输出框架结论与需要用户补齐的字段清单，不得给具体仓位建议
