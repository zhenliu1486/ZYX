# 短剧编剧套路

竖屏短剧的爆款创作方法论。核心目标：**每3秒一个钩子，每15秒一个反转，让人停不下来**。

## 核心原则

### 短剧 vs 传统影视的区别

| 维度 | 传统影视 | 竖屏短剧 |
|---|---|---|
| 节奏 | 慢热，铺垫长 | 开头3秒必须抓人 |
| 冲突 | 慢慢积累 | 每15秒一个冲突/反转 |
| 人物 | 复杂多面 | 标签化，一眼看懂 |
| 台词 | 含蓄 | 直接、金句、打脸 |
| 结尾 | 完整 | 每集留钩子，必须看下一集 |

---

## 黄金三秒钩子公式

开头3秒决定用户划走还是留下。以下钩子类型任选一种：

### 1. 冲突式
```
直接上冲突画面 + 一句狠话
```
**示例**：
> （画面：女主被扇耳光）"就你也配嫁进我们家？"

### 2. 反差式
```
一个惊人的反差画面
```
**示例**：
> （画面：保洁阿姨走进宴会厅，所有人震惊）"她怎么来了？"

### 3. 身份揭露式
```
一句话揭露隐藏身份
```
**示例**：
> "对不起，我不是保洁，我是这家公司的董事长。"

### 4. 悬念式
```
一个让人想知道答案的问题
```
**示例**：
> "结婚三年，我才发现丈夫的真实身份。"

## 每集节奏模板（2分钟/集）

```
0-3秒：钩子（抓人）
3-15秒：交代本集冲突
15-60秒：冲突升级
60-90秒：第一个反转/小高潮
90-105秒：跌入低谷/新的麻烦
105-120秒：结尾钩子（必须看下一集）
```
