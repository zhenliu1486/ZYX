## 兵王归来套路

### 核心爽点
- 隐藏身份、装逼、护短
- 在外是兵王，回家是普通人

### 典型设定
- 男主是特种部队兵王，退伍回来
- 表面是普通上班族/保安/司机
- 实际身份是顶尖高手

### 经典桥段
1. **被轻视名场面**：所有人都看不起男主，觉得他是废物
2. **装逼名场面**：关键时刻出手，一招搞定
3. **亮身份名场面**：别人查他背景，吓傻了
4. **护短名场面**：谁动我女人/家人，我弄谁

### 装逼公式
```
别人看不起 → 有人欺负他家人 → 男主出手 → 一招搞定 → 所有人震惊
```

## 赘婿逆袭套路

### 核心爽点
- 三年赘婿、忍辱负重、真实身份揭露
- 所有人都骂他软饭男，结果是大佬

### 典型设定
- 男主入赘女方家，被全家看不起
- 实际上是顶级家族继承人/隐世高手
- 三年期满，恢复身份

### 经典桥段
1. **受气名场面**：开局被丈母娘、老婆、亲戚各种羞辱
2. **忍耐名场面**：男主忍了三年，只为一个承诺
3. **期满名场面**："三年期满，该回家了"
4. **打脸名场面**：亮出身份，所有人跪下
5. **追妻名场面**：老婆后悔了，想复合

## 都市修仙套路

### 核心爽点
- 重生、修仙、无敌
- 在都市里用修仙能力装逼

### 典型设定
- 男主是修仙界大佬，重生到现代
- 或者现代普通人获得修仙能力
- 在都市里降维打击

### 经典桥段
1. **被看不起名场面**：同学聚会，所有人炫富
2. **出手名场面**：有人出事，男主用医术/武功解决
3. **美女青睐名场面**：校花/女总裁/女杀手都爱上男主
4. **势力震惊名场面**：古武世家、地下势力都臣服

## 神医/绝世高手套路

### 核心爽点
- 被低估、救人、打脸
- 表面是普通人， actual 是神医/高手

### 典型设定
- 男主是隐世神医，下山历练
- 或者是退伍军医/中医传人
- 用医术救人，顺便装逼

### 经典桥段
1. **被质疑名场面**："这么年轻能看病？"
2. **救人名场面**：别人治不好的病，男主一针搞定
3. **大佬感谢名场面**：被救的人是顶级大佬，当场报恩
4. **医术比试名场面**：和老中医/外国医生比试，碾压

## 系统流套路

### 核心爽点
- 开挂、升级、任务奖励
- 普通人获得系统，一路升级

### 典型设定
- 男主获得一个系统（签到系统/抽奖系统/任务系统）
- 完成任务获得奖励
- 一路从弱到强

### 经典桥段
1. **获得系统名场面**：男主人生低谷，系统激活
2. **第一次奖励名场面**：获得第一个能力/钱
3. **任务名场面**：系统发布任务，男主完成获得奖励
4. **升级名场面**：越来越强，身边的人越来越震惊

## 男频通用装逼节奏

每5集一个小高潮：

| 集数 | 内容 |
|---|---|
| 1-3集 | 男主被欺负到极点 |
| 4-5集 | 第一次出手，小装逼 |
| 6-10集 | 收拾一批小反派 |
| 11-15集 | 遇到更强的对手 |
| 16-20集 | 大装逼，亮身份 |
| 21-30集 | 最终boss战 |

### 打脸三要素
1. **先抑**：把男主踩得越低越好
2. **后扬**：反击越爽越好
3. **围观**：必须有人围观，越多人震惊越好
