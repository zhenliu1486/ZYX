# 与豆包 personal agent 结合

> 依据（2026-11-24 核实）：豆包的「技能」是 Agent 能力扩展单元，可通过 PC 端「技能·连接器·伙伴 → 我的技能 → 上传技能」拖入含 `SKILL.md` 的文件夹或压缩包；豆包工作另有「工作伙伴」，可配置人设并挂载技能；个人助理方向的新产品「小豆」处于邀请制公测，主打主动服务、记忆与后台任务，但**没有公开 API**。
> 所以结合点不在私有接口，而在**技能 + 记忆 + 定时任务**三层；R7 只读本机/云端文件，不外发。

## 1. 四层结合

| 层 | 做法 | 对应命令 |
|---|---|---|
| 能力层 | 库建在豆包云端可持久访问的位置：默认 `~/Doubao/wiki/<slug>/`（`ZYX_WIKI_HOME` 可覆盖）；手机与 PC 会话共用同一个库 | `wiki.py init` |
| 记忆层 | 把 `slug / root / topic` 记成一条稳定事实（例如「我的知识库叫 ai-research，在 ~/Doubao/wiki/ai-research」）；每次会话开头读简报，而不是整库塞进上下文 | `wiki.py where`、`wiki.py brief` |
| 主动性 | 用豆包的任务/定时提醒每周跑一次巡检，把断链、缺页、孤儿、陈旧页推给用户；小豆的后台跟进正好承接 | `wiki-lint.py`、`brief --with-lint` |
| 分发层（可选） | 把周检简报或综述页写进飞书文档/消息；需用户逐次授权，不自动外发 | 由宿主文档/消息能力完成 |

## 2. 在豆包里安装（PC 端）

1. 打包：在仓库根目录执行
   ```bash
   bash scripts/package-doubao.sh --only wiki-vault
   # 需要路由能力时再打 zyx 包
   bash scripts/package-doubao.sh --only zyx
   ```
   产物在 `dist/doubao/<skill>.zip`（内含 `<skill>/SKILL.md`）。
2. 打开豆包 PC →「技能·连接器·伙伴」→「我的技能」→「新建 / 上传技能」→ 拖入 zip 或直接拖入 `skills/wiki-vault` 文件夹。
3. 安装后可直接在任务里说「建个知识库」「把这篇文章加进我的库」触发；也可在「工作伙伴」里新建一个「知识库管家」，把 `wiki-vault`（可选 `zyx`）挂上去。

## 3. 会话里的用法

- **开头**：`python3 scripts/wiki.py brief --with-lint` → 一屏内看清库里有什么、最近做了什么、哪些缺口。
- **记一条**：把原料放进 `raw/`，说「ingest 这篇」；流程见 `operations.md`。
- **问一句**：说「我库里关于 X 有什么结论」，先 `search` 再作答，不拿常识冒充库内结论。
- **周末体检**：看 `brief --with-lint` 或 `wiki-lint.py` 报告；要修就按优先级修。
- **别做**：不要把整库内容贴进对话；不要并行开两个会话写同一个库。

## 4. 定时任务建议（需用户确认后创建）

在豆包「任务」页建一条每周任务，指令写成：

> 每周日 18:00 帮我体检知识库：运行 `python3 <wiki-vault目录>/scripts/wiki-lint.py <库根>`，把断链、缺页、孤儿、陈旧页各列 3 条，并给下一步建议；结果用 5 行以内发我。

对应脚本参数：库根用 `wiki.py where` 取，避免写死路径。R7 本身**不自动创建任务**；是否建、几点跑由用户定。

## 5. 移动端回复规范

- 先给结论 2 行，再展开细节；超过 5 行先给摘要。
- 不贴超长表格；需要清单时用 3–5 条短句。
- 每条回答末尾附「库位置」或「下一步」，方便下次接着做。
- 语音场景下避免读长路径，只说库名。

## 6. 隐私与边界

- 库默认只落本机/本工作区；`sync --pull/--push` 仍未实现，不产生远端写。
- `raw/` 只读；入库前脱敏（手机号、身份证、客户名以占位符替代）。
- 不做小豆私有接口对接、不猜测未公开能力；只使用公开的技能上传、记忆与任务能力。
- 不替用户自动创建/修改任务；需要时给现成指令，由用户确认。

## 7. 与「工作伙伴」人设的配合

推荐人设：**知识库管家**——先查库再回答、不确定就说不确定、每次改动留日志、每周主动报缺口。
完整可粘贴的人设与快捷指令见仓库 `docs/doubao/personal-agent-profile.md`。
