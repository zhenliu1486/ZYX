## 什么是人物弧光

人物弧光 = 人物从开场到结尾的变化轨迹。

好的弧光不是"人变厉害了"，而是"人想通了"——从相信一个谎言，到认识到真相。

```
开场：相信的谎言（缺陷）
  ↓ 经历事件
中点：动摇、怀疑
  ↓ 跌入谷底
觉醒：看清真相
  ↓ 做出选择
结尾：活出真相（成长）
```

## 三种经典弧光

### 1. 正向弧光（成长型）

**最常见**：主角从有缺陷/被谎言蒙蔽，到觉醒成长。

| 阶段 | 状态 | 示例（被解雇的女主） |
|---|---|---|
| 开场 | 相信谎言 | "我必须讨好所有人才能被爱" |
| 经历 | 被现实打击 | 被解雇、被抛弃 |
| 谷底 | 谎言破碎 | 发现讨好没用，没人真的爱她 |
| 觉醒 | 认识真相 | "我不需要讨好别人，我本身就有价值" |
| 结尾 | 活出真相 | 独立、自信、按自己的方式活 |

### 2. 负向弧光（堕落型）

**悲剧/反派**：主角从好人，一步步走向堕落。

| 阶段 | 状态 | 示例（野心家） |
|---|---|---|
| 开场 | 有理想 | "我要改变世界" |
| 经历 | 为了目标妥协 | 用了不光彩的手段 |
| 中点 | 越陷越深 | 得到权力，但失去原则 |
| 谷底 | 彻底黑化 | 为了权力牺牲所有人 |
| 结尾 | 被吞噬 | 拥有一切，但一无所有 |

### 3. 平弧光（坚守型）

**硬汉/侦探**：人物本身不变，但改变了周围的世界。

| 阶段 | 状态 | 示例（侦探） |
|---|---|---|
| 开场 | 坚守原则 | "真相就是真相" |
| 经历 | 世界诱惑/威胁他 | 给钱、威胁、美女 |
| 考验 | 是否动摇 | 一度想放弃 |
| 坚守 | 最终坚持 | 不管怎样，要查到底 |
| 结尾 | 改变世界 | 坏人被绳之以法，世界变好了 |

## 弧光设计模板

为每个主要人物填写以下表格：

### 主角弧光表

| 项目 | 内容 |
|---|---|
| 姓名 | |
| 开场状态 | （外在：过着什么生活；内在：相信什么谎言） |
| 核心缺陷 | （阻碍他成长的最大问题） |
| 触发事件 | （什么事打破了他的日常） |
| 第一次动摇 | （什么时候开始怀疑自己） |
| 中点转折 | （假胜利/假失败） |
| 跌入谷底 | （最低谷是什么） |
| 觉醒时刻 | （什么时候想通了） |
| 最终选择 | （最后关头他做了什么） |
| 结尾状态 | （变成了什么样的人） |
| 主题 | （这个弧光表达了什么道理） |

## 反派设计要点

好的反派不是"坏"，而是"另一个正确答案"。

| 要点 | 说明 |
|---|---|
| 反派有自己的逻辑 | 他觉得自己是对的 |
| 反派与主角镜像 | 两人追求同一件事，但方法不同 |
| 反派足够强大 | 必须给主角制造真正的威胁 |
| 反派有弱点 | 他的缺陷最终导致失败 |
| 反派有人性 | 不是纯粹的恶，有可怜/可恨之处 |
