# 电影剧本开发

从一个故事点子到完整剧本框架的方法论工具。核心目标：**先搭骨架再填肉，结构对了故事就成了一半**。

## 核心工作流

### 第一步：一句话故事（Logline）

先能用一句话说清你的故事：

```
[主角] + [意外事件] + [目标] + [阻碍] + [结果]
```

**示例**：
> 一个被解雇的女白领，意外发现自己是隐形富豪的亲生女儿，在争夺家产的过程中，她必须选择金钱还是真爱。

**检查标准**：
- [ ] 15秒内能说完
- [ ] 有明确的主角
- [ ] 有明确的冲突
- [ ] 有转折/意外

---

### 第二步：三幕结构搭建

详见 [references/three-act-structure.md](references/three-act-structure.md)。

```
第一幕：建置（25%）—— 日常世界 → 触发事件 → 决定出发
第二幕：对抗（50%）—— 困难重重 → 中点转折 → 跌入谷底
第三幕：解决（25%）—— 最终决战 → 觉醒成长 → 新的日常
```

**关键节点**：
| 节点 | 位置 | 作用 |
|---|---|---|
| 触发事件 | 10% | 打破日常，故事开始 |
| 第一转折点 | 25% | 主角做出选择，进入新世界 |
| 中点 | 50% | 假胜利/假失败，局势反转 |
| 第二转折点 | 75% | 跌入谷底，看似失败 |
| 高潮 | 90% | 最终决战 |
| 结局 | 100% | 新的日常，主题升华 |

---

### 第三步：人物弧光设计

详见 [references/character-arc.md](references/character-arc.md)。

每个主要人物必须有清晰的弧光：

```
开场状态（缺陷/谎言）→ 经历事件 → 觉醒/转变 → 结尾状态（成长/真相）
```

**三种经典弧光**：
1. **正向弧光**：从有缺陷到成长（大多数主角）
2. **负向弧光**：从好人到堕落（反派/悲剧）
3. **平弧光**：人不变，但改变了世界（硬汉/侦探类）

---

### 第四步：节拍表填充

使用"救猫咪"15节拍表，逐拍填充具体事件。详见 [references/beatsheet.md](references/beatsheet.md)。

---

### 第五步：主题提炼

用一句话说清这个故事想表达什么：

```
这个故事讲的是 [主角] 在 [事件] 中，最终明白 [道理/真相]。
```

**示例**：
> 这个故事讲的是被解雇的女白领在争夺家产的过程中，最终明白真正的财富不是金钱，而是爱与自我价值。
