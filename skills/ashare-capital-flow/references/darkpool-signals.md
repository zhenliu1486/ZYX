# 暗盘资金与席位信号识别手册

## 一、为什么需要「暗盘」这一层

盘中看到的大单是位置最靠后的信息：等你在盘口看到 1 万手买进，往往已经是第三手信息。真正的强势资金在**盘前竞价、大宗、席位、筹码结构**里留下痕迹，这些痕迹不在分时图上，但对 2-4 周波段的方向判断价值更高。

## 二、六类信号的操作化识别

### 1. 集合竞价异动（09:15-09:25）
- 09:15-09:20 为可撤单阶段，此阶段的巨量买单多为试盘或诱多，可信度打折
- 09:20-09:25 为不可撤单阶段，此阶段的放量 + 高开才是真金白银
- 有效信号：09:20-09:25 匹配量 ≥ 昨日同期 3 倍，虚拟开盘价高于昨收 ≥3%，且竞价量占昨日成交额 >2%
- 反向信号：09:25 前面临大量撤单、虚拟价快速回落 → 有人在跑

### 2. 尾盘 15 分钟大单
- 14:45-15:00 出现连续同向大单且收盘价收在当日高位 → 次日有承接意愿
- 尾盘拉高但量能不放 → 多为做收盘价，偏虚假
- 尾盘放量砸盘 → 次日低开概率大

### 3. 龙虎榜席位
三种席位性质不同：
- **一线游资**（知名营业部）：做连板与题材，持续性 2-5 日，出货快
- **机构专用**：偏趋势与基本面，持续性 2-8 周，适合波段跟
- **量化席位**：高频对倒，次日多为震荡，无方向指引

判定规则：
- 买一占比 >25% 且为游资 → 一家独大，次日兑现概率高，不追
- 买一为机构 + 买二为游资 → 最健康组合（趋势 + 情绪双支撑）
- 同一席位 3 日内二次出现 → 主力在做，愿意暴露，波段可跟
- 卖出席位为「机构专用」且金额大 → 机构撤离，警惕

### 4. 大宗交易
- 溢价成交（溢价 >0）：接货方愿意高于市价买，通常视为偏多
- 小幅折价（0-5%）：正常流动性折价，中性
- 大额折价（>8%）：多为减持或资金出逃，短期偏空
- 买方为「机构专用」+ 溢价 → 最有价值的偏多信号
- 注意：大宗有时是股东之间的过户、质押配套，若同期有减持/质押公告，按偏空处理

### 5. 盘后固定价格交易
- 申报量突增且连续多日出现 → 有资金在做盘后配置
- 结合次日竞价看是否延续

### 6. 筹码集中度
- 股东户数环比减少 >10% 且户均持股上升 → 筹码向少数人集中，中长期偏多
- 股东户数快速增加 + 股价高位 → 派发给散户
- 数据披露有滞后（月/季），只能作为结构性证据，不做短线依据

## 三、信号叠加计分

| 命中数量 | 且方向为吸筹 | 且方向为出货 | 方向矛盾 |
|---|---|---|---|
| ≥3 条 | +15 分，置信度高 | -15 分 | 0（视为分歧） |
| 1-2 条 | +8 分 | -8 分 | 0 |
| 0 条 | 0（中性 50 分） | — | — |

## 四、常见造假与误判

- 拆单算法把一笔大单拆成数十笔小单 → 用「净额」而非「单笔」判断
- 对倒：同一资金自买自卖制造净流入假象 → 必须用龙虎榜或大宗交叉验证
- 护盘资金：股价下跌时托单但不出货，看起来净流入，实际是延缓下跌
- 指数调整、ETF 被动申赎带来的持股变化 ≠ 主动看多

## 五、取数路径

- `seed_finance_lookup`：个股行情、估值、部分资金类指标
- `seed_finance_search`：公告（大宗交易、增减持、股东户数、减持计划）
- `general_search`：当日龙虎榜解读、游资动向快讯
- 用户提供的同花顺/东财截图：可直接读取净流入、席位、大宗字段

任一数据不可得时，标明「该项缺失，不计入暗盘信号统计」，不得推测席位名称或金额。
